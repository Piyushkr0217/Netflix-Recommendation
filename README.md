# Netflix-Recommendation

This project builds a movie recommendation system using the Singular Value Decomposition (SVD) algorithm to predict user ratings and recommend movies based on collaborative filtering techniques.
The system analyzes large-scale user-movie rating data, identifies hidden patterns in user preferences, and generates personalized movie recommendations.

Key Features :-

  Data preprocessing and cleaning of large rating datasets
  Exploratory Data Analysis (EDA) using Pandas & Matplotlib
  Collaborative Filtering using SVD algorithm
  Personalized movie recommendations
  Model evaluation using RMSE
  Efficient handling of large datasets
